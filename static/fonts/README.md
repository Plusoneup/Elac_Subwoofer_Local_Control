# Fonts used by the "Retro pixel" theme

| File | Font | Licence |
|---|---|---|
| `PressStart2P-Regular.ttf` | Press Start 2P (CodeMan38) | SIL Open Font License 1.1, see `OFL-PressStart2P.txt` |
| `VT323-Regular.ttf` | VT323 (Peter Hull) | SIL Open Font License 1.1, see `OFL-VT323.txt` |

Both are the unmodified files from the google/fonts repository (`ofl/pressstart2p`, `ofl/vt323`).
They are bundled so the panel works without internet access.

# Textures and pictures

- `../textures/black-ash.jpg` (fine grain, Debut and Gunmetal) and `../textures/black-ash-2.jpg`
  (wider, deeper grain, Black ash) are generated by `tools/make_textures.py` from seeded random
  noise. No photographs are used; both tile seamlessly.
- `../sub3030-icon.png` and `../sub3030-mini.png` are rendered from `tools/subwoofer.svg`, an
  original drawing of a generic cube subwoofer with no brand marks.

All of these are original work of this project.
